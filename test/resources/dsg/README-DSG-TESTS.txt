This folder contains DSG Excel files used for integration-style ingestion tests.

- DSG-STD-test.xlsx : Minimal DSG workbook with InfoSheet, STD, SSD and possibly other sheets, crafted to represent a valid ingestion scenario.
- DSG-SSD-test.xlsx : Optional: focused SSD-only workbook for specific SSD-related ingestion tests.

These files are used by tests under org.hascoapi.tests to exercise the ingestion pipeline against realistic metadata templates.
