Esta diferença de namespace (`kb/default` vs `ont/arrowhead`) indica que:
- O DA-SOC foi configurado para um namespace diferente, OU

## CONSULTAS SPARQL ÚTEIS

### Contar objetos em qualquer SOC
```sparql
PREFIX hasco: <http://hadatac.org/ont/hasco#>
SELECT ?soc (COUNT(?obj) as ?count) WHERE {
  {
    ?obj hasco:isMemberOf ?soc .
  } UNION {
    GRAPH ?g {
      ?obj hasco:isMemberOf ?soc .
    }
  }
} GROUP BY ?soc
```

### Listar todos os SOCs e seus objetos
```sparql
PREFIX hasco: <http://hadatac.org/ont/hasco#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?soc ?socLabel ?obj ?originalID WHERE {
  ?soc a hasco:StudyObjectCollection .
  OPTIONAL { ?soc rdfs:label ?socLabel }
  OPTIONAL {
    GRAPH ?g {
      ?obj hasco:isMemberOf ?soc .
      OPTIONAL { ?obj hasco:originalID ?originalID }
    }
  }
} LIMIT 100
```
